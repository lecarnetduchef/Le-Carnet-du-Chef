# Menus PDF

Les trois emplacements attendus par la page publique sont :

- `menu1.pdf`
- `menu2.pdf`
- `menu3.pdf`

L'espace ADMIN permet de remplacer les PDF publiés via Firebase Storage sans modifier le code du site.

Les fichiers PDF commerciaux ne sont pas générés automatiquement : ils doivent contenir les informations réelles du Carnet du Chef.
