GESTION DES PDF

1. Cliquez sur « Remplacer le PDF ».

2. Sélectionnez votre nouveau fichier PDF.

3. Vérifiez le fichier sélectionné.

4. Cliquez sur « SAUVEGARDER LES PDF ».

5. Attendez le message « PDF sauvegardés avec succès ».
Les modifications ne sont réellement publiées sur le site qu’après la sauvegarde.

Les PDF sont stockés dans Firebase Storage et leurs URLs publiées sont enregistrées dans Firestore. Aucun autre contenu du site n'est géré ici.
