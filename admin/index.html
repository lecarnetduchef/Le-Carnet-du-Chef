🍽️ PRODUITS / STOCKS

Phase 1 — base produits

Cette rubrique prépare les produits vendables. Aucun paiement ni réservation de stock client n’est géré ici.

Le stock vendu et le stock réservé ne sont jamais modifiés par l’ajustement manuel du stock disponible.

Ajuster le stock disponible

Sélectionnez d’abord un produit avec « Modifier ». Cette action ne change ni le stock vendu ni le stock réservé.

📖 Les 3 menus PDF

GESTION DES PDF

1. Cliquez sur « Remplacer le PDF ».

2. Sélectionnez votre nouveau fichier PDF.

3. Vérifiez le fichier sélectionné.

4. Cliquez sur « SAUVEGARDER LES PDF ».

5. Attendez le message « PDF sauvegardés avec succès ».
Les modifications ne sont réellement publiées sur le site qu’après la sauvegarde.

Les PDF sont stockés dans Firebase Storage et leurs URLs publiées sont enregistrées dans Firestore. Aucun autre contenu du site n'est géré ici.
